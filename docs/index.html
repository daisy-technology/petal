How it works

Click a name to rename it

Petal lists every Desktop on every display in Mission Control order. Clear a name and it goes back to "Desktop 3".

Give each one a color

The flower in the menu bar takes the color, and a thin edge in that color frames the Desktop, including in Mission Control.

Nothing to set up

No account and no network access. Petal never asks for Accessibility or Screen Recording permissions.

The labels inside Mission Control itself stay "Desktop 1, 2, 3". macOS only allows changing those with System Integrity Protection turned off, and Petal won't ask you to do that.

First launch

Petal isn't notarized by Apple yet, so macOS stops it the first time you open it.

  1. Unzip Petal.zip and drag Petal to Applications.
  2. Open it. When macOS says it can't verify the developer, click Done.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

Or run this once in Terminal: xattr -dr com.apple.quarantine /Applications/Petal.app

Windows and Linux

Petal is Mac only for now. Versions for Windows and Linux are planned. Watch the repository to hear when they ship.
